# Phase 6

## 用户反馈修复

### 天堂陨落长弓
- 修复巨大绿色/黄色矩形光束。
- 所有矩形光束缩放改为按纹理实际宽高换算，并增加长度上限。
- HeavenRainbowImpact 恢复为“1600 像素线判定 + 不直接绘制实体巨型光柱”的旧版思路。
- ParadiseArrow / VientianePunishment 改为短小受控的彩虹绘制。

### 寰宇贪婪镐
恢复旧版核心逻辑：
- 镐形态右键：从玩家位置向鼠标方向发射高速抹除光线，沿路径逐块抹除。
- 锤形态右键：只在鼠标位置执行约 500x500 范围抹除，并可拆墙。
- 被抹除的 Tile 掉落物、容器内物品会被收集。
- 操作结束后只生成一个带完整内容的暗物质球。
- 使用旧版 Pedestruct 音效。
- 绑定键检测移回 InfinitePick.HoldItem；切换时直接交换 Pickaxe/Hammer 贴图与工具属性。

### 无限马桶
- 正式加入 `using Terraria.GameContent ;`。
- 恢复 `PlayerSittingHelper.ChairSittingMaxDistance` 距离判定。
